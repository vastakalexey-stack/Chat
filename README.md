# GPT — Android launcher for ChatGPT

Минималистичное Android-приложение, которое открывает официальный сайт ChatGPT в браузере телефона.

## Возможности
- Одна кнопка для открытия https://chatgpt.com/
- Вход через обычную страницу авторизации OpenAI в браузере
- История чатов, голос и загрузка файлов доступны на стороне официального ChatGPT согласно возможностям аккаунта и браузера

## API и сервер
Приложение не использует OpenAI API, YandexGPT или GigaChat. Не нужны API-ключи, backend, отдельная оплата API или сервер. Вход и общение выполняются на официальном сайте ChatGPT.

## Сборка APK
Откройте GitHub Actions и запустите workflow **Build AI Duo APK**. Скачайте артефакт **AI-Duo-debug-apk** и установите APK на Android.

Минимальная версия Android: 8.0 (API 26).

## Важное замечание
Это не самостоятельный клиент и не встроенная копия ChatGPT: приложение открывает официальный сайт во внешнем браузере. Доступность ChatGPT зависит от поддерживаемых OpenAI стран и региональных ограничений.
