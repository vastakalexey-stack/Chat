# Размещение backend AI Duo в Amvera Cloud

Этот репозиторий подготовлен для запуска Node.js/Express backend из корня проекта.

## 1. Создать приложение

1. Откройте https://amvera.ru/ и войдите или зарегистрируйтесь.
2. Создайте новое приложение.
3. Подключите GitHub-репозиторий `vastakalexey-stack/Chat`.
4. Выберите сборку через Dockerfile в корне репозитория.
5. После первого успешного запуска откройте настройки приложения и добавьте переменные окружения из раздела ниже.

## 2. Переменные окружения

Добавьте в настройках приложения (значения берите из своих кабинетов; не отправляйте их в чат и не коммитьте в GitHub):

- `YANDEX_API_KEY` — API-ключ Yandex Cloud AI Studio.
- `YANDEX_FOLDER_ID` — ID каталога Yandex Cloud.
- `YANDEX_MODEL` — `yandexgpt-5.1`.
- `YANDEX_WEB_SEARCH_ENABLED` — `true`.
- `GIGACHAT_AUTH_KEY` — Authorization Key из кабинета разработчика GigaChat.
- `GIGACHAT_SCOPE` — `GIGACHAT_API_PERS`.
- `GIGACHAT_MODEL` — `GigaChat-2-Pro`.
- `PORT` — `8080`.

Не публикуйте API-ключи и не помещайте их в Android-приложение.

## 3. Проверка

После запуска откройте адрес приложения с путём `/health`. Ожидается JSON с `ok: true`.

Затем адрес backend нужно будет прописать в Android-проекте вместо `https://YOUR-BACKEND-HOST/` и собрать APK заново.

## Важно

Пока backend не развернут и API-ключи не добавлены, запросы к YandexGPT и GigaChat работать не будут. Публичный адрес приложения сам по себе не означает, что AI-провайдеры настроены. Для защиты от чужого использования перед публикацией API нужно добавить пользовательскую авторизацию/токен приложения и ограничение доступа.
